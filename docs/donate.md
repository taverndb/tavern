# Support Tavern

Donations help support Tavern's continued development and maintenance.

[![Verify recipient on BscScan](https://img.shields.io/badge/Verify%20recipient-BscScan-f0b90b?style=for-the-badge)](https://bscscan.com/address/0xcF69E336cE485d691f07421126B80552d3C6AE6b)

## Donate native BNB

Tavern accepts **native BNB only** on **BNB Smart Chain Mainnet** (chain ID
`56`). Scan the QR code below with a compatible wallet, then verify the
recipient and network in the wallet before approving the transfer.

![QR code for the Tavern BNB Smart Chain donation recipient](donate/bsc-mainnet-address.svg)

The QR code encodes an EIP-681 payment identifier for BNB Smart Chain Mainnet.
Use the BscScan button above to independently verify the recipient before
sending funds.

## Important

- Send funds only on BNB Smart Chain Mainnet. Transfers on another network may
  be unrecoverable.
- Do not send BEP-20 tokens; they are not accepted.
- Cryptocurrency transfers are irreversible.
- Donations are voluntary and are not tax-deductible.
